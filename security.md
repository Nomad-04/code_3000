# Repository Security

## Intended Users

This repo contains coursework for CSE 3000. It is intended for the student accessing it (Nomar) and course instructors/teaching assistants grading it. 

## Security Risks
A security risk is solutions to problems may be exposed if someone were to find it inside the code. Another risk is the possibility of accidentally committing passwords, keys, or other PII / sensitive information. 

## Safeguards
- The repo includes a `CODEOWNERS` file assigning ownership to `@batmandoescalc`. For students personal use, this file is not necessary because students are the only ones expected to contribute to the repo.
- As a security measure, keep the repo limited to the coursework materials. No other files should be added to the repo unless stated otherwise by coursework instructions.
- Review changes before committing them. Check for any included secrets or sensitive data.
- Pull-request rulesets are not necessary for its current use because there is no sensitive data in this repo.
- Make sure read and write access is assigned to trusted people.
